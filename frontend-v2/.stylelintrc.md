# Why `overflow-y` / `overflow-x` are exempt from the logical-property rule

Everything else in this codebase uses logical properties, because that is what
makes Hebrew a genuine right-to-left layout rather than a mirrored one.

`overflow-y` is the exception. Right-to-left changes the **inline** axis; it
does not change the block axis. A vertical scroll container scrolls the same
way in English and in Hebrew, so `overflow-block` buys no correctness here -
and it is a materially newer property (Chrome 118, Firefox 125, Safari 17) than
`overflow-y`, which every browser has supported for two decades.

Trading universal support for zero behavioural gain is the wrong trade, so the
two physical overflow properties are exempt and nothing else is.
